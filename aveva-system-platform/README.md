# AVEVA System Platform skill

Le fichier central est **[SKILL.md](SKILL.md)**. Il décrit quand et comment une IA doit assister un ingénieur sur Application Server, QuickScript .NET, OMI ou Industrial Graphics.

Ce skill est un **outil de travail**, pas un manuel constructeur ni une certification de compatibilité. Les exemples `.qsnet` sont illustratifs et ne remplacent pas les essais dans l'environnement cible.

## Contenu

- [SKILL.md](SKILL.md) : procédure d'analyse, de génération et de vérification.
- [Références officielles](references/official-sources.md) : sources et politique de preuve.
- [Checklist technique](references/review-checklist.md) : points de contrôle et tests.
- [Exemples](examples/README.md) : scripts illustratifs.
- [Guide IA](../GUIDE_IA.md) : usage avec Codex, ChatGPT, Claude et Microsoft Copilot.

## Compatibilité

Utiliser ce dossier comme skill seulement dans les environnements qui reconnaissent les **Agent Skills**. Sinon, transmettre `SKILL.md` comme instructions et joindre les références nécessaires.

**Toujours vérifier la documentation officielle de la version logicielle ciblée**, même si le skill a déjà été utilisé sur une autre mission.
